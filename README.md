# MATH SI Attendance

Math SI Attendance is a website to help CSUF Math SI Leaders sign in students to TitanNet automatically. It leverages Justin Stitt's [si-attendance](https://github.com/JustinStitt/si-attendance) backend by providing users with an UI that interacts with this API.

## Setup / Development

Clone the repository and install all the dependencies:

```bash
git clone https://github.com/tomasohCHOM/math-si-attendance.git
cd math-si-attendance
npm install
```

Then start the development process:

```bash
npm run dev
```

To build and start in production mode, run the following:

```bash
npm run build
npm run preview
```
